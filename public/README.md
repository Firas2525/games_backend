# SM Store - Landing Page 🚀

صفحة هبوط (Landing Page) عصرية، خفيفة، وسريعة جداً لتطبيق **SM Store** لشحن الألعاب والبطاقات الرقمية.

---

## 🌟 المميزات
- **تصميم Dark Gaming Mode فخم:** تأثيرات نيون زرقاء وخضراء متناسقة مع هوية التطبيق.
- **عربي RTL بالكامل:** خط Cairo أنيق وتجربة مستخدم مريحة للهواتف والكمبيوتر.
- **أزرار تحميل التطبيق (APK):**
  - زر مباشر لتحميل ملف `SM-Store.apk`.
- **ربط حي وديناميكي مع الباك إند:**
  - يتم جلب رقم واتساب الدعم الفني مباشرة وبشكل حي من إعدادات المتجر في الباك إند.
- **عدادات وإحصائيات تفاعلية:** تعمل بحركات سلسة عند التمرير.
- **أقسام متكاملة:**
  - البانر الرئيسي والتعريف بالتطبيق (Hero Section).
  - شاشة محاكاة حية للتطبيق (App Mockup).
  - مميزات التطبيق (Features).
  - أشهر الألعاب والبطاقات المدعومة (Supported Games).
  - خطوات الشحن البسيطة (How it works).
  - بطاقة التحميل الكبرى (Download CTA).
  - الأسئلة الشائعة بنظام الأكورديون (FAQ).
  - الدعم الفني وسياسة الخصوصية وحقوق الملكية.

## 🚀 طرق الاستضافة والتشغيل المجاني 100%

### الطريقة 1: تعمل الآن تلقائياً وبشكل مجاني فوري! ⚡
تم ربط هذه الصفحة مع خادم الباك إند الحالي على Render، وبالتالي يمكنك زيارتها فوراً مجاناً عبر:
👉 **`https://games-backend-c0h7.onrender.com/`**

---

### الطريقة 2: رفعها على Vercel برابط واسم نطاق مخصص مجاني (الأسرع والأفضل) 🌐
1. توجه إلى [Vercel.com](https://vercel.com) وسجل دخولك مجاناً عبر حساب GitHub.
2. اضغط **Add New Project** واختر مستودع `games_landing` أو اسحب المجلد مباشرة.
3. اضغط **Deploy**، وخلال 10 ثوانٍ ستحصل على رابط عالمي فائق السرعة مجاني مدى الحياة مع شهادة أمان SSL مثل:
   `https://sm-store.vercel.app`

---

### الطريقة 3: رفعها على Render كـ Static Site (مجاني مدى الحياة) ☁️
1. في لوحة تحكم [Render Dashboard](https://dashboard.render.com).
2. اضغط **New +** ثم اختر **Static Site**.
3. اختر مستودعك، واضبط مسار النشر (Publish directory) على: `games_landing` أو `public`.
4. اضغط **Create Static Site** لتحصل على رابط مثل:
   `https://sm-store.onrender.com`

---

### الطريقة 4: GitHub Pages 🐙
1. ادخل إلى إعدادات المستودع في GitHub -> **Settings** -> **Pages**.
2. اختر فرع `main` والمجلد `/` أو `/games_landing`.
3. اضغط Save وستعمل مجاناً على نطاق github.io.

---

## 📲 كيفية ربط ملف التطبيق (APK) المباشر
- يمكنك ببساطة وضع ملف الـ APK الخاص بتطبيقك داخل المجلد باسم:
  `SM-Store.apk`
- أو فتح ملف `index.html` وتعديل السطر التالي لاستبداله برابط مباشر من Google Drive أو Mediafire:
  ```html
  <a href="https://your-download-link-here.apk" class="btn btn-hero btn-download-lg">
  ```
